# Phonebook - Full-Stack App

Full-stack contact management application with React frontend and Node.js backend from Full Stack Open (Parts 2 and 3).

**Frontend:** React
**Backend:** Node.js + Express

## Features

- Create, edit, search, delete contacts
- Users view, single and all contacts

## How To Run Locally

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev

```
